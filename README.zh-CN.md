# AI 工具发布清单

供 AI 工具创始人、开发者和小团队使用的六阶段行动模板，覆盖发布前30天到发布后30天，共30项。内容由 AI 工具目录 Toolso.AI 维护，帮助安排产品表述、素材、渠道规则、测量、客服和复盘。示例为虚构材料，不代表真实运营成果。

[English](README.md)

## 开始使用

1. 将[中文独立清单](CHECKLIST.zh-CN.md)复制到自己的项目笔记或私有任务中，无须安装程序。
2. 填写产品、发布日期、时区、负责人、主要目标与观察期。补做任务时，分别记录原计划日期和实际操作日期。
3. 每项记录负责人、截止时间、依赖、状态、证据和下一步；可参照[虚构填写示例](examples/launch-record.example.md)。
4. 只有证据实际存在时才勾选完成。缺少审批或平台条件时记录暂缓；依赖需要更长时间时调整日期。

六个阶段是规划检查点。平台审核时间、观察期及团队发布条件以实际要求为准，清单不保证审核、排名、外链或营收。按受众匹配和当前规则选择推广渠道。

## 链接与成效记录

每个渠道设置一个主要目标链接，统一UTM来源、活动及内容标识。[UTM示例表](examples/utm-links.example.csv)使用保留的示例域名和虚构参数，使用前须替换。canonical不加推广参数，URL参数中不放私人信息。

发布后记录实际URL及可见状态，区分草稿、已提交、已批准、链接可见、索引请求已接受和实际收录。复盘使用相同统计期和分母，排除测试流量，区分未知数据和真实零值。密码及客户记录保存在公开模板之外。

发布日期和时区：

## T-30：定义发布
- [ ] T30-01: 记录受众、输入、有效输出、访问条件和实际限制。
- [ ] T30-02: 定义主要目标、衡量窗口、基线和测试排除规则。
- [ ] T30-03: 筛选渠道，并记录各渠道的受众、准入条件、规则和审核要求。
- [ ] T30-04: 确认现有账号及归属人；将凭据保存在密码管理器中。
- [ ] T30-05: 指定交付、审批、支持和事件处理负责人；列出阻碍发布的依赖。

## T-14：准备发布素材包
- [ ] T14-01: 检查落地页的工作流程、限制、定价依据、支持渠道和主要链接。
- [ ] T14-02: 检查移动端布局、元数据、规范 URL、抓取访问权限、站点地图覆盖情况和目标 URL。
- [ ] T14-03: 截取清晰的工作流程截图并准备必需演示；确认隐私和复用权限。
- [ ] T14-04: 批准一致的产品描述、分类、定价来源和关系披露说明。
- [ ] T14-05: 使用一致的 UTM 值登记渠道链接；规范 URL 中不包含活动参数。

## T-7：演练
- [ ] T07-01: 在全新会话中使用安全示例数据，测试从外部链接到有效输出的完整流程。
- [ ] T07-02: 验证归因和目标事件；移除重复事件，并记录测试排除规则。
- [ ] T07-03: 重新检查账号访问权限、产品归属、渠道准入条件、链接、披露说明和审批。
- [ ] T07-04: 演练支持、升级处理和取消服务信息，并在适当的测试环境中检查支付。
- [ ] T07-05: 记录每个渠道的发布或暂缓决策，以及尚未解决的依赖。

## T0：发布日
- [ ] T00-01: 重新检查承诺的工作流程和重大故障；取得所需的发布和内容审批。
- [ ] T00-02: 发布获允许且已批准的内容；记录实际 URL、账号、时间、时区和可见状态。
- [ ] T00-03: 检查线上文案、目标页面、披露说明和 UTM；区分提交、批准、链接可见和索引状态。
- [ ] T00-04: 在适用时请求搜索发现或索引，并保留返回结果；之后验证索引状态。
- [ ] T00-05: 处理实质性问题和故障；避免组织投票、重复推广和未经请求的消息群发。

## T+7：复盘首周
- [ ] T07P-01: 在相同窗口内比较访问和有效行动；区分测试、缺失数据和观察到的零值。
- [ ] T07P-02: 按产品理解、激活、输出质量、定价和信任对反馈分类；保留非敏感证据。
- [ ] T07P-03: 制定精简的修正清单，明确负责人、优先级和验证标准；重新检查已变化的表述。
- [ ] T07P-04: 按各平台的流程检查待审核提交；避免重复提交或重新发布已移除的内容。
- [ ] T07P-05: 决定继续、调整或暂缓哪些工作；进一步参与前重新检查社区规则。

## T+30：规划下一轮
- [ ] T30P-01: 比较获客、持续使用、支持投入和商业结果，明确时间段和分母。
- [ ] T30P-02: 核对商业数据时，区分发票、实收款项、退款和未经核实的归因。
- [ ] T30P-03: 为下一轮实验分配时间和预算，并说明理由和停止条件。
- [ ] T30P-04: 在获授权的范围内更新文档、目录记录、支持答复，以及实际链接或索引状态。
- [ ] T30P-05: 记录决策、负责人、证据和变更；分享客户材料或公开资源前取得许可。
